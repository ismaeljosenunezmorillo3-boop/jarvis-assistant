# JARVIS Assistant 🤖

A voice-controlled AI assistant for your computer, inspired by the JARVIS from Iron Man.

## Features

- 🎤 Voice recognition and natural language processing
- 🔊 Text-to-speech responses
- ⏰ Time and date queries
- 🔍 Web search capabilities
- 🌐 Browser automation
- 🎯 Extensible command system
- ⚙️ Easy configuration

## Installation

### Prerequisites

- Python 3.8 or higher
- Microphone for voice input
- Speakers for voice output

### Setup

1. Clone the repository:
```bash
git clone https://github.com/ismaeljosenunezmorillo3-boop/jarvis-assistant.git
cd jarvis-assistant
```

2. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\\Scripts\\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Start JARVIS:
```bash
python jarvis.py
```

Then speak commands like:
- "What time is it?"
- "What's today's date?"
- "Search for Python tutorials"
- "Open browser"
- "Goodbye" (to exit)

## Available Commands

| Command | Example |
|---------|----------|
| Time | "What time is it?" |
| Date | "What's today's date?" |
| Search | "Search for machine learning" |
| Browser | "Open browser" |
| Help | "Help" |
| Exit | "Goodbye" or "Exit" |

## Configuration

Edit `config.json` to customize:
- Voice speed
- Voice volume
- Language settings
- Custom commands
